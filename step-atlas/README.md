# СТЕПЬ — Атлас Астраханского края

Первая локальная версия интерактивной карты, подготовленная для дальнейшего развития в Telegram Mini App.

## Запуск локально

1. Распакуйте архив.
2. Откройте терминал в папке проекта.
3. Если установлен Python, выполните:

```bash
python -m http.server 8000
```

4. Откройте `http://localhost:8000`.

Нужен интернет: Leaflet, подложка OpenStreetMap и погода Open-Meteo загружаются с внешних ресурсов. JSON-файл точек загружается через `fetch`, поэтому не открывайте `index.html` напрямую через `file://`.

## Исправления в этой версии

- Плашка погоды поднята на мобильных экранах, чтобы не перекрывать кнопки зума.
- Поиск включает слой найденной точки и синхронизирует чекбокс/навигацию.
- Геолокация использует один маркер, который перемещается при повторном запросе.
- Состояние нижней навигации синхронизируется с видимостью слоёв и инициализируется при старте.
- У рыбалки и природы разные символы маркеров.
- Карточка закрывается по Escape и системной кнопке Telegram «Назад», получает фокус, а Tab удерживается внутри диалога. Закрытая карточка скрыта от клавиатурной навигации через `inert` и `visibility`.
- Подключён Telegram Web App SDK; вызываются `ready()` и `expand()`. Цвета светлого интерфейса не переопределяются параметрами Telegram, чтобы не ломать контраст и легенду.
- Добавлены `viewport-fit=cover` и безопасные отступы.
- Точки вынесены в `data/points.json`; записи поддерживают `verified`, `sources` и `updatedAt`.

## Важно

- Точки пока демонстрационные, не используйте их как проверенные рекомендации для поездки.
- Рыболовный календарь с редакторской проверкой ещё не готов: текущая оценка клёва — эвристика по сезону и погоде, а не прогноз.
- SDK Telegram можно проверить локально только частично. Для реального запуска Mini App нужен доступный по HTTPS адрес и настройка бота через Telegram.
- Тайлы стандартного сервера OpenStreetMap подходят для разработки и небольшого тестирования. Перед публичным запуском с существенным трафиком выберите провайдера тайлов и соблюдайте его условия использования.
- Не публикуйте точные координаты уязвимых видов и закрытых/охраняемых территорий без проверки правил доступа.

## Структура

- `index.html` — интерфейс.
- `styles.css` — оформление и адаптивная вёрстка.
- `app.js` — логика карты и Telegram SDK.
- `data/points.json` — карточки точек. Файл должен лежать именно в папке `data/`, так как `app.js` загружает `data/points.json` относительно корня сайта.


### Совместимость с Telegram перед публикацией

- В Telegram Web App версии 7.7 и выше вызывается `disableVerticalSwipes()`, если метод доступен, чтобы вертикальный жест не сворачивал приложение во время работы с картой и карточками.
- Основные файлы должны иметь имена `index.html`, `styles.css`, `app.js`; данные — `data/points.json`.
- При публикации нужен HTTPS-адрес. Его можно разместить на GitHub Pages, Cloudflare Pages или Netlify, а затем указать в настройках Telegram-бота через BotFather.
- Для публичной карты следует выбрать провайдера тайлов и соблюдать его условия использования.


### Источники и клавиатурная навигация

- URL в `sources` выводятся как ссылки только для `http:` и `https:`; ссылки открываются с `target="_blank"` и `rel="noopener noreferrer"`.
- При закрытии панели слоёв клавишей Escape фокус возвращается на кнопку «Слои карты».
- Перед публикацией проверьте, что имена файлов — `index.html`, `styles.css`, `app.js`, а JSON лежит в `data/points.json`.


## Погода, рыбы, растения, фото

- `weather.js` — чистые функции: запрос к Open-Meteo (без ключа), разбор ответа, оценка клёва 0–100 по каждому виду, советы рыбаку (мороз, жара, ветер, гроза, туман, лёд, нерестовый запрет) и пожелание удачи. Модуль можно проверять в Node.
- `data/fish.json` — каталог рыб: месяцы пика и «берёт слабее», комфортный диапазон температуры воздуха, время суток и объяснение «почему тогда». Это редакторская оценка, её нужно вычитать.
- `data/points.json` — 9 точек: 5 рыболовных ориентиров, 2 места (Баскунчак, Самосделка) и 2 точки природы (Астраханский заповедник, Богдо-Баскунчак). Поле `fish` ссылается на `fish.json`, `plants` — список растений (поле `rare` для редких), `photos` — фото.
- Формат фото: `{"url": "https://...", "alt": "...", "author": "...", "license": "CC BY-SA 4.0", "sourceUrl": "https://..."}`. Показываются только `https`-адреса; без `photos` карточка пишет, что фото появятся после проверки лицензий. Берите снимки без людей и всегда указывайте автора и лицензию (CC BY и CC BY-SA требуют атрибуции).
- Нерестовый запрет (16 мая — 20 июня) взят из публикации «Вокруг света». Правила меняются: сверяйте с Волго-Каспийским территориальным управлением Росрыболовства.
- Координаты `coordsVerified: true` взяты из справочников; у Астрахани и Харабали `false`: это ориентиры по населённому пункту, их надо сверить и сдвинуть на реальный участок.


## Слои, кружки и фото из Wikimedia Commons

- Маркеры — цветные кружки: синий — рыбалка, зелёный — места (степь, история, заповедные уголки), оранжевый — природа (птицы, звери, растения).
- Точки «Места» и «Природа» поддерживают `history` (три периода: Российская империя, СССР, сегодня) и `species` (обитатели с фото, статусом охраны и заметкой).
- Фото задаются так: `{"file": "Имя файла.jpg", "author": "...", "license": "CC BY-SA 4.0", "alt": "..."}`. Картинка грузится с Commons через `Special:FilePath`, а под ней всегда выводятся автор, лицензия и ссылка на страницу файла. Лицензии CC BY и CC BY-SA требуют именно такой подписи.
- Фото рыб и птиц — это снимки вида, сделанные не в Астраханской области: у орлана снимок из Польши, у степного орла из Непала, у лотоса общий снимок цветка. Подпись «не с места» стоит в заметках.
- Что проверить глазами до публикации: на фото нет людей (я не мог просмотреть изображения), лицензия файла «В поисках Итиля.jpg» (автор Ted.ns), полное имя автора файла «Mount Bolshoye Bogdo in Astrakhan Oblast.JPG» (ник ksogomonov), и что файлы с Commons открываются по указанным именам.
