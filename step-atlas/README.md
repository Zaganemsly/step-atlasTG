# СТЕПЬ — Атлас Астраханского края

Первая локальная версия интерактивной карты, подготовленная для дальнейшего развития в Telegram Mini App.

## Запуск локально

1. Распакуйте архив.
2. Откройте терминал в папке проекта.
3. Если установлен Python, выполните:

```bash
python -m http.server 8000
```

4. Откройте `http://localhost:8000`.

Нужен интернет: OpenLayers, подложка OpenStreetMap и погода Open-Meteo загружаются с внешних ресурсов. JSON-файл точек загружается через `fetch`, поэтому не открывайте `index.html` напрямую через `file://`.

## Исправления в этой версии

- Плашка погоды поднята на мобильных экранах, чтобы не перекрывать кнопки зума.
- Поиск включает слой найденной точки и синхронизирует чекбокс/навигацию.
- Геолокация использует один маркер, который перемещается при повторном запросе.
- Состояние нижней навигации синхронизируется с видимостью слоёв и инициализируется при старте.
- У рыбалки и природы разные символы маркеров.
- Карточка закрывается по Escape и системной кнопке Telegram «Назад», получает фокус, а Tab удерживается внутри диалога. Закрытая карточка скрыта от клавиатурной навигации через `inert` и `visibility`.
- Подключён Telegram Web App SDK; вызываются `ready()` и `expand()`. Цвета светлого интерфейса не переопределяются параметрами Telegram, чтобы не ломать контраст и легенду.
- Добавлены `viewport-fit=cover` и безопасные отступы.
- Точки вынесены в `data/points.json`; записи поддерживают `verified`, `sources` и `updatedAt`.

## Важно

- Точки пока демонстрационные, не используйте их как проверенные рекомендации для поездки.
- Рыболовный календарь с редакторской проверкой ещё не готов: текущая оценка клёва — эвристика по сезону и погоде, а не прогноз.
- SDK Telegram можно проверить локально только частично. Для реального запуска Mini App нужен доступный по HTTPS адрес и настройка бота через Telegram.
- Тайлы стандартного сервера OpenStreetMap подходят для разработки и небольшого тестирования. Перед публичным запуском с существенным трафиком выберите провайдера тайлов и соблюдайте его условия использования.
- Не публикуйте точные координаты уязвимых видов и закрытых/охраняемых территорий без проверки правил доступа.

## Структура

- `index.html` — интерфейс.
- `styles.css` — оформление и адаптивная вёрстка.
- `app.js` — логика карты и Telegram SDK.
- `data/points.json` — карточки точек. Файл должен лежать именно в папке `data/`, так как `app.js` загружает `data/points.json` относительно корня сайта.


### Совместимость с Telegram перед публикацией

- В Telegram Web App версии 7.7 и выше вызывается `disableVerticalSwipes()`, если метод доступен, чтобы вертикальный жест не сворачивал приложение во время работы с картой и карточками.
- Основные файлы должны иметь имена `index.html`, `styles.css`, `app.js`; данные — `data/points.json`.
- При публикации нужен HTTPS-адрес. Его можно разместить на GitHub Pages, Cloudflare Pages или Netlify, а затем указать в настройках Telegram-бота через BotFather.
- Для публичной карты следует выбрать провайдера тайлов и соблюдать его условия использования.


### Источники и клавиатурная навигация

- URL в `sources` выводятся как ссылки только для `http:` и `https:`; ссылки открываются с `target="_blank"` и `rel="noopener noreferrer"`.
- При закрытии панели слоёв клавишей Escape фокус возвращается на кнопку «Слои карты».
- Перед публикацией проверьте, что имена файлов — `index.html`, `styles.css`, `app.js`, а JSON лежит в `data/points.json`.


## Погода, рыбы, растения, фото

- `weather.js` — чистые функции: запрос к Open-Meteo (без ключа), разбор ответа, оценка клёва 0–100 по каждому виду, советы рыбаку (мороз, жара, ветер, гроза, туман, лёд, нерестовый запрет) и пожелание удачи. Модуль можно проверять в Node.
- `data/fish.json` — каталог рыб: месяцы пика и «берёт слабее», комфортный диапазон температуры воздуха, время суток и объяснение «почему тогда». Это редакторская оценка, её нужно вычитать.
- `data/points.json` — 5 ориентиров. Поле `fish` ссылается на `fish.json`, `plants` — список растений (поле `rare` для редких), `photos` — фото.
- Формат фото: `{"url": "https://...", "alt": "...", "author": "...", "license": "CC BY-SA 4.0", "sourceUrl": "https://..."}`. Показываются только `https`-адреса; без `photos` карточка пишет, что фото появятся после проверки лицензий. Берите снимки без людей и всегда указывайте автора и лицензию (CC BY и CC BY-SA требуют атрибуции).
- Нерестовый запрет (16 мая — 20 июня) взят из публикации «Вокруг света». Правила меняются: сверяйте с Волго-Каспийским территориальным управлением Росрыболовства.
- Координаты `coordsVerified: true` взяты из справочников; у Астрахани и Харабали `false`: это ориентиры по населённому пункту, их надо сверить и сдвинуть на реальный участок.


## Версия 2 (обновление)

- `photos.js` — фото из Wikimedia Commons во время работы (автор и лицензия подписываются автоматически). Рыбы: фото самой рыбы, без людей и снастей. Места: по запросам `photoQueries` из `points.json`, затем по соседним; один снимок не повторяется в разных точках.
- `data/points.json` — 30 точек (по 10: рыбалка, природа, места). Поле `geocode` — запрос к OpenStreetMap: координаты населённого пункта уточняются при загрузке (кэш 30 дней). Точки с `coordsVerified: true` взяты из найденных источников. Остальные — ориентиры, их нужно сверить.
- Поиск: сначала точки атласа, затем адреса по всей Астраханской области (Nominatim, `bounded` по границам области). Работают также координаты вида `46.35, 48.03`.
- «◎» — определение местоположения: Telegram LocationManager → браузерная геолокация (сначала быстрая, затем точная). Если не вышло, можно указать старт тапом по карте. Тап по синему кружку — выбор пункта назначения; маршрут рисуется через OSRM, открывается в Яндекс, Google, 2ГИС или OSM.
- Шанс поймать: минимальный / низкий / ниже среднего / средний / хороший / высокий, лучшее время суток и ближайший пик сезона. Это эвристика, а не прогноз.
- 20 пожеланий лежат в `weather.js` (`WISHES`): рыбалка, виды, отдых, путешествия; подбираются по типу точки и не повторяются подряд.

## Версия 4: клёв по погоде, запреты, навигация внутри приложения

**Оценка клёва** (`weather.js`). Единой научной формулы клёва нет, поэтому оценка — эвристика по советам рыболовных изданий. Учитываются: давление и его изменение за 3 и 24 часа, температура, ветер и порывы, облачность, зорька и закат, сезон вида и фаза Луны. Фразы вердикта разные для каждого уровня и меняются с условиями (давление, жара, ветер, время суток). Это ориентир, а не гарантия.

**Запреты** (`data/bans.json`, `bans.js`). Кнопка «Запреты» внизу открывает календарь: что действует сегодня, что скоро начнётся, годовая шкала и постоянные правила (ямы, виды, размеры, нормы, снасти). В карточке рыболовной точки есть краткий блок. Данные собраны вручную из новостей и пересказов приказа № 695, дата сверки в поле `checkedAt`. Это не живая лента Росрыболовства. Раз в год и после новостей о новых приказах обновляйте файл: сроки в `rules`, дату в `checkedAt`. Запрет на воблу в файле задан на 2026 год и закончится 31 декабря.

**Навигация** (`nav.js`). Кнопка «Поехать в приложении» ведёт по маршруту OSRM: стрелка и подсказки по-русски, голос (по желанию), пересчёт при съезде. Если дорога обрывается, подсказка переключается на направление по азимуту. Ограничения: нужен открытый экран (в фоне навигация не работает), точность зависит от GPS в Telegram, публичный сервер OSRM без гарантий работы и только для автомобилей. Ссылки на внешние карты остались.

Новые файлы: `bans.js`, `nav.js`, `data/bans.json`. Версия скриптов в `index.html` поднята до `?v=4`.

### Версия 5
- Загрузка фото устойчивее: не больше двух запросов к Commons одновременно, повтор при сбое, пустые ответы больше не запоминаются на неделю. Если фото не пришли, под галереей рыбы, растения или животного есть кнопка «Повторить». Галереи рыб подгружаются при прокрутке, по 4 фото.
- `data/photo-blocklist.json` — список запрещённых фото (по части адреса). Туда внесено фото Харабали.
- На карте всегда есть плашка «Маршрут»: «Я здесь (определить)», «Старт на карте», «Куда ехать». После выбора точек появляется кнопка «Продолжить здесь» (навигация внутри приложения) рядом с ссылками на внешние карты.
- v9: второй источник фото рыб, растений и животных — iNaturalist (api.inaturalist.org, снимки с авторами и CC-лицензиями). Он подключается, когда Commons не дал четыре подходящих фото.

### Версия 10
- Видов рыбы стало 19: добавлены берш, плотва, густера, синец, сапа (белоглазка), чехонь, краснопёрка, линь, карась, белый амур, толстолобик, голавль. У каждой точки есть свои «встречается часто / иногда / редко» (`fishFreq` в `data/points.json`). Это справочные данные, а не наблюдения в точке. Редкие виды показываются, но в оценку клёва не входят.
- У каждого вида в `data/fish.json` есть блок `legal` (минимальный размер и норма по пересказу Правил, источник — те же, что в `data/bans.json`). Перед публикацией сверьте с официальным текстом.
- Слой «Заправки и магазины» (`services.js`): данные OpenStreetMap через Overpass API по текущему экрану. Заправки и рыболовные магазины видны с масштаба 9, продуктовые магазины с 12. Базы отдыха намеренно не показываются. Список зависит от того, что внесено в OSM.

### Версия 12: зафиксированные фото и режим редактора
- `data/photos.json` — готовая подборка фото мест, рыб, растений и животных. Если файл есть, у всех пользователей показываются именно эти снимки; поиск по Commons и iNaturalist работает только как запасной вариант, если снимок перестал открываться.
- Кнопка ✕ и служебные кнопки видны только в режиме редактора. Включить: открыть приложение с `?edit=1` (например `https://zaganemsly.github.io/step-atlasTG/step-atlas/?edit=1`), выключить: `?edit=0`.
- Как обновить подборку: в режиме редактора убрать плохие фото крестиком, открыть «Слои» и нажать «Зафиксировать подборку фото и скачать». Скачанный `photos.json` загрузить в `step-atlas/data`.

## v17: другой движок карты

Движок карты заменён с Leaflet на OpenLayers (открытый проект международного сообщества, лицензия BSD-2).
Файл `map-engine.js` даёт приложению те же простые функции карты (маркеры, подсказки, линии маршрута), поэтому остальной код не менялся.
Подключение: `ol.js` и `ol.css` с cdn.jsdelivr.net (запасной адрес unpkg.com), проверка целостности SRI включена.
Заправки и рыболовные магазины читаются из `data/services.json` (выгрузка OpenStreetMap от 23.10.2026).
